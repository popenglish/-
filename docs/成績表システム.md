### 点数_A タブ

- 1行目＝満点：`満点,4,10,4,5,3,6,8,4,6`（合計50点＝テスト満点）
- 2行目＝見出し：`名前,代名詞,疑問詞,時を表す語,副詞1,副詞2,前置詞,be動詞,be動詞の疑問・否定,三単現のs`
- A3＝`=入力_中一A!A2` を下にドラッグ（名前が自動で並ぶ）
- B3から＝先生が正解数を手入力

### 数式（実際に動いているもの。コピペ用）

**◎○△への変換（入力_中一A の B2 に貼り、右へJ2までドラッグ→下へドラッグ）**
```
=IF(点数_A!B3="","",IFS(点数_A!B3>=点数_A!B$1*0.8,"◎",点数_A!B3>=点数_A!B$1*0.5,"○",TRUE,"△"))
```
⚠️ この式は**絶対に点数タブに貼らない**（循環参照エラーになる）。
⚠️ 貼る前に、その範囲の◎○△プルダウン（入力規則）を削除しておく。

**通知表の評価セル（通知表_中一A のC列。数字＝入力タブの列番号）**
```
=IFERROR(VLOOKUP($B$2,入力_中一A!$A:$P,6,FALSE),"")
```
※ 6 の部分を項目ごとに 2〜15 に変える。コメント欄は 16。
※ 古いセルには項目名で探すMATCH式が残っているが、**新規はこの列番号式に統一**（MATCH式は項目名が1文字違うと空白になる。副詞2で実際に起きて、この式への置き換えで解決した）。

**通知表のつくり**
- A1＝タイトル、A2＝「名前：」、B2＝生徒名プルダウン（入力規則→範囲 `入力_中一A!A2:A100`）
- A5から下＝項目名（日本語と英語を同じセル、スラッシュ区切り）
- B5から下＝説明文（日本語のみ・保護者向け・専門用語禁止）
- C5から下＝上の評価式
- 凡例：`学習状況・・・ ◎（十分達成しています）　○（おおむね達成しています）　△（努力をしましょう）　ー（欠席）`
