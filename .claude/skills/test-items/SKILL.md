# /test-items — テストから通知表の評価項目を作る

テスト（Googleドキュメント）の中身を読んで、通知表に使う**評価項目＋説明文＋満点表**を、そのままコピペできる形で作る。

## 手順

1. **テストの中身を手に入れる**
   - URLかドキュメントIDをもらったら、Google Drive のツール（`read_file_content`）で読む
   - 読めなければ「ドキュメントの中身をコピーして貼ってください」とお願いする
2. **大問ごとに文法・単語のかたまりを分析**して、評価項目にまとめる
   - 項目数は**10個前後まで**に絞る（多すぎたら似たものを統合）
   - 複数の大問が同じ文法なら1項目にまとめ、満点は合算する
3. **3点セットを作って出す**（下の出力形式で）

## 作るものと決まり

### ① 評価項目名（通知表のA列用）

- 日本語と英語を**同じセルに**入れる形。区切りはスラッシュ：`代名詞 / Pronouns`
- 外国人の先生も読めるようにするための英語表記
- **縦一列のコピペブロック**で渡す（一番上のセルに貼ると下に広がる）

### ② 説明文（通知表のB列用）

- **日本語のみ**。保護者が読んで分かるやさしい言葉で
- **文法の専門用語は禁止**：SVOO・SVOC・不定詞の名詞的用法…などはダメ
  - 例：SVOO →「『人に物をあげる』などの文の形」
  - 例：三単現のs →「he や she のときの動詞の形（plays など）」
- 「〜できるか。」の形でそろえる
- 縦一列のコピペブロックで渡す

### ③ 満点表（点数タブの1行目用）

- テストの配点を項目ごとに合計する。**合計がテストの満点と一致するか必ず検算**して、検算結果も見せる
- カンマ区切りの1行で渡す：`満点,4,10,4,5,3,6,8,4,6`
- あわせて見出し行も：`名前,代名詞,疑問詞,…`
- 貼り方の案内：「A1セルを1回クリック→⌘V→データ→テキストを列に分割→カンマ」

## 出力形式（この順で）

1. 項目と満点の対応表（確認用。どの大問がどの項目かも書く）
2. コピペブロック①：項目名（縦）
3. コピペブロック②：説明文（縦）
4. コピペブロック③：入力タブ見出し（カンマ1行）＋満点行（カンマ1行）

## 注意

- スピーキングはテストに含まれないが、通知表には必要 → 項目の最後に「スピーキング / Speaking」を足すか確認する
- 返事は日本語で、1ステップずつやさしく
- 過去の例：中一A＝代名詞・疑問詞・時を表す語・副詞1・副詞2・前置詞・be動詞・be動詞の疑問文と否定文・三単現のs（満点 4,10,4,5,3,6,8,4,6＝計50点）
