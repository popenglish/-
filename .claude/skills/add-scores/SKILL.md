# /add-scores — 既存クラスに点数タブを追加してテストを反映

紙テスト（Googleドキュメント）を読んで、**そのクラスの通知表の評価項目に当てはめ**、
「点数タブ（正解数を手入力）→ 入力タブ（◎○△に自動変換）→ 通知表」の仕組みを作る。

test-items（テストから項目を新規に作る）と違い、こちらは**すでに評価項目が決まっているクラス**に、
テストの点数入力の仕組みを後付けする作業。中一Aで作った仕組みと同じ形にそろえる。

## 前提

- メインのスプレッドシート：ID `1USHJ1JGM-trt8bCdkh9qwT9ksJo1hAl6tAOYlP3vpeM`
- タブ名の付け方：`入力_クラス名`／`通知表_クラス名`／`点数_クラス名`（例：入力_中一C、点数_C）
- **タブ名に算用数字を使わない**（漢数字。中一C は OK、"C" は英字なので OK）
- ユーザーは日本語話者・初心者。**1〜2ステップずつ**案内し、「できた」を待つ

## 全体の手順

1. **テストを読む**（`read_file_content` にドキュメントIDを渡す。読めなければ本文を貼ってもらう）
2. **クラスの評価項目を確認する**：ユーザーに項目リストを聞く（もう通知表にある項目）。無ければ test-items で先に項目を作る
3. **テストの大問を、クラスの項目に割り当てる**（下記ルール）。**必ず検算**：
   - 「点数」の合計＝テストの満点と一致するか（例：50点）
   - 「問題数」の合計も出す（満点タブに使う値）
4. **ズレを洗い出して、推測せずユーザーに確認する**（下記「ズレの扱い」）
5. 確認できたら、**点数タブ → 入力タブの変換式 → 手動列の設定** を1ステップずつ案内する

## テストの割り当てルール

- 大問ごとに文法・単語のかたまりを見て、クラスの項目に対応づける
- 複数の大問が同じ項目なら合算する（問題数も点数も足す）
- **満点タブに入れる数字＝「問題数（その項目の問題の数）」**。先生は「正解した数」を打つので、◎○△は「正解数 ÷ 問題数」で決まる
  - ⚠️ テストに 0.5点問題などがあると、**問題数の合計 ≠ テストの満点**になる。これは正常。「満点タブの数字は問題数です（テストの点数とは別）」と必ず説明する
  - 同じ項目の中で配点が違う問題が混ざると、問題数での比率は多少ずれるが、◎○△の判定には十分。気にしすぎない
- **ボーナス問題（チャレンジ等）**も項目にできる（問題数だけ入れる。未回答は空白でOK）

## ズレの扱い（推測せず必ず確認する）

テストとクラスの項目は、たいていピッタリ合わない。次の3種類に分けて、ユーザーに確認する：

1. **テストにあるのに、クラスの項目に無い**（例：代名詞・三単現がテストに出ているが項目に無い）
   → 「その項目の列を足して自動反映するか／入れないか」を聞く
2. **クラスの項目にあるのに、テストに無い**（例：連語・動詞・形容詞）
   → その列は**手動で◎○△を付ける列**にする（点数タブには入れない）と伝える
3. **分け方・入れ場所があいまい**（例：副詞1と副詞2の境目、三単現を「動詞」に入れるか別列にするか）
   → 選択肢を出して選んでもらう（AskUserQuestion のボタンが親切）
4. **点数も大問番号も無い謎のセクション**がテストに紛れていたら、消し忘れの可能性。無視するか含めるか確認する

## 作るもの（確認が済んだら、この順で1ステップずつ）

### ステップ1：点数タブ（例 点数_C）

- タブ名は式で使うので**正確に**（例 `点数_C`）
- A1＝満点行：`満点,5,6,3,…`（各項目の**問題数**をカンマ区切り。A1に貼って「データ→テキストを列に分割」）
- A2＝見出し行：`名前,代名詞,疑問詞,…`（自動反映する項目だけを、入力タブと同じ順で）
- A3＝`=入力_クラス名!A2` を入れて下にドラッグ（名前が自動で並ぶ）
- B3から先生が**正解数を手入力**

### ステップ2：入力タブに変換式

- **入力タブの B2** に貼る（⚠️ 点数タブには絶対貼らない＝循環参照 #REF! になる）：
```
=IF(点数_C!B3="","",IFS(点数_C!B3>=点数_C!B$1*0.8,"◎",点数_C!B3>=点数_C!B$1*0.5,"○",TRUE,"△"))
```
- 貼る前に、その範囲の◎○△プルダウン（入力規則）を削除しておく
- B2に貼ったら、**自動反映する項目の最後の列まで右へドラッグ** → その後、生徒の人数分だけ下へドラッグ
- 基準：満点（問題数）の 8割以上＝◎、5割以上＝○、未満＝△、未入力＝空白

### ステップ3：手動列

- テストに無い項目（連語・動詞・形容詞・スピーキングなど）は、変換式を入れず、**◎○△のプルダウン**で手入力
- 「データ → データの入力規則 → プルダウン → ◎,○,△,-」

### ステップ4：通知表の確認

- 通知表の評価式は**列番号で直接取る形**（項目名で探すMATCH式は文字違いで壊れるので使わない）：
```
=IFERROR(VLOOKUP($B$2,入力_クラス名!$A:$列,列番号,FALSE),"")
```
- 新しく足した項目（例：代名詞・三単現）は、通知表にも行を足して式を入れる

## 大事な注意

- **入力タブの列の順番＝点数タブの見出しの順番**にそろえる（変換式を右にドラッグしたとき正しく対応するため）
- 実際のタブ名は**ユーザーにコピーして貼ってもらう**（全角・半角の事故防止）。自分の推測で書かない
- セルは**1回クリックしてから⌘V**（ダブルクリック禁止）
- 貼り付け素材は「カンマ1行＋テキストを列に分割」か「縦ブロック」で渡す
- できあがったら docs/成績表システム.md のクラス表を更新する
- 返事は日本語・専門用語なし・絵文字でやさしく

## 中一C の実例（このスキルで作った記録）

テスト：中1英語②後半（クリスティーナ先生）50点満点。
満点行（問題数）：`満点,5,6,3,3,3,8,13,8,3,4,6,3`
見出し：`名前,代名詞,疑問詞,時を表す語,副詞,副詞2,頻度の副詞,前置詞,be疑問否定,Can,Do/Does,三単現,現在進行形`
手動列：連語・動詞・形容詞。ズレの確認で「代名詞の列を足す／副詞=1-C・副詞2=7-B/三単現の列を足す」と決定。
