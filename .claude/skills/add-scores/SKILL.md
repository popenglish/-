# /add-scores — 既存クラスに点数タブを追加してテストを反映

紙テスト（Googleドキュメント）を読んで、**そのクラスの通知表の評価項目に当てはめ**、
「点数タブ（正解数を手入力）→ 入力タブ（◎○△に自動変換）→ 通知表」の仕組みを作る。
**クラスやテストが変わっても、この手順どおりにやれば同じ品質で作れる。**

test-items（テストから項目を新規に作る）と違い、こちらは**すでに評価項目が決まっているクラス**に、
テストの点数入力の仕組みを後付けする作業。

## 前提

- メインのスプレッドシート：ID `1USHJ1JGM-trt8bCdkh9qwT9ksJo1hAl6tAOYlP3vpeM`
- タブ名：`入力_クラス名`／`通知表_クラス名`／`点数_クラス名`（例：入力_中一C、点数_C）
- **タブ名に算用数字を使わない**（漢数字。中一C はOK、"C" は英字なのでOK）
- ユーザーは日本語話者・初心者。**1〜2ステップずつ**案内し、「できた」を待つ
- **特定のタブの中身は `read_file_content` では読めない**（一番左のタブしか返らない）。入力タブの並びを知りたいときは**スクリーンショットを送ってもらう**のが確実（ユーザーは画像を送るのが得意）

## 全体の流れ

1. **テストを読む**（`read_file_content` にドキュメントIDを渡す。読めなければ本文を貼ってもらう）
2. **クラスの評価項目と入力タブの並びを確認する**：入力タブの見出し行の**スクショ**をもらう（列の順番・手動列の位置・すでに入っている点数を把握するため）。項目が未定なら先に test-items で作る
3. **テストの大問を、クラスの項目に割り当てる**。**必ず検算**：
   - 「点数」の合計＝テストの満点（例：50点）
   - 「問題数」の合計（満点タブに使う値）
4. **ズレを洗い出して、推測せず確認する**（下記「ズレの扱い」）
5. **点数タブを作る**（スクリプトが速い。下記「実装の型」）
6. **入力タブに変換式を入れる**（列の並びに合わせて。下記「実装の型」）
7. **手動列は触らない**／**通知表を確認**

## テストの割り当てルール

- 大問ごとに見て、クラスの項目に対応づける。複数大問が同じ項目なら合算
- **満点タブに入れる数字＝「問題数」**。先生は「正解した数」を打つ。◎○△は「正解数 ÷ 問題数」で決まる
  - ⚠️ 0.5点問題などがあると**問題数の合計 ≠ テストの満点**。これは正常。「満点タブの数字は問題数です」と必ず説明
- **ボーナス問題**も項目にできる（問題数だけ入れる。未回答は空白でOK）
- **教室独自の分け方・用語を優先**（docs/成績表システム.md「教室独自の分け方」を必ず確認。例：中一Cでは with/about 等を「副詞2」と呼ぶ）

## ズレの扱い（推測せず必ず確認・AskUserQuestionのボタンが親切）

1. **テストにあるのに項目に無い**（例：代名詞・三単現）→「列を足して自動反映するか／入れないか」を聞く
2. **項目にあるのにテストに無い**（例：連語・動詞・形容詞・スピーキング）→**手動で◎○△を付ける列**（点数タブには入れない）
3. **分け方・入れ場所があいまい**（副詞の境目、三単現を動詞に入れるか別列か）→選択肢を出す
4. **点数も番号も無い謎のセクション**→消し忘れの可能性。無視か含めるか確認

## 実装の型（具体的な数式・スクリプト）

### 点数タブを自動で作るスクリプト（Apps Script）

`満点`と`見出し`の中身をそのテスト用に書き換えて渡す。`入力タブ名`も実際の名前に。

```javascript
function 点数タブ作成() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const 入力タブ名 = '入力_中一C';   // ★実際の入力タブ名（違ったら直す）
  const 点数タブ名 = '点数_C';       // ★

  const 満点   = ['満点',5,6,3,6,6,8,7,8,3,4,6,3];        // ★各項目の問題数
  const 見出し = ['名前','代名詞','疑問詞','時を表す語','副詞','副詞2','頻度の副詞','前置詞','be疑問否定','Can','Do/Does','三単現','現在進行形']; // ★

  const 入力 = ss.getSheetByName(入力タブ名);
  if (!入力) { SpreadsheetApp.getUi().alert('入力タブ「'+入力タブ名+'」が見つかりません'); return; }
  let sh = ss.getSheetByName(点数タブ名);
  if (sh) sh.clear(); else sh = ss.insertSheet(点数タブ名);
  sh.getRange(1,1,1,満点.length).setValues([満点]);
  sh.getRange(2,1,1,見出し.length).setValues([見出し]);
  const 名前 = 入力.getRange('A2:A'+入力.getLastRow()).getValues().filter(r => r[0] !== '' && r[0] != null);
  if (名前.length) sh.getRange(3,1,名前.length,1).setValues(名前);
  sh.setFrozenRows(2);
  SpreadsheetApp.getActive().toast('点数タブを作りました ✅ B3から正解数を入れてください', '完了', 6);
}
```

→ これで点数タブに **満点行(1行目)・見出し(2行目)・生徒名(3行目〜)** が入る。先生はB3から正解数を打つ。
手貼りする場合は、満点行を A1 に、見出し行を A2 にカンマ貼り＋「テキストを列に分割」。

### 変換式（◎○△）を入力タブに入れる

⚠️ **式は入力タブに入れる。点数タブに入れると循環参照 #REF!。**
⚠️ **行ズレ注意**：点数タブは満点行があるぶん、生徒が1行下（点数タブ3行目＝入力タブ2行目が同じ生徒、のことが多い）。式の中の点数タブの行番号は**点数タブ側の生徒の行**を書く。

**基本の1マス分**（項目が点数タブのX列、満点がX$1、生徒が点数タブのS行目）：
```
=IF(点数_C!X{S}="","",IFS(点数_C!X{S}>=点数_C!X$1*0.8,"◎",点数_C!X{S}>=点数_C!X$1*0.5,"○",TRUE,"△"))
```
- **直接参照（点数_C!C3）を使う**。VLOOKUPだと未入力セルが 0 と読まれて全部△になる罠がある。直接参照なら「未入力＝空白」が正しく出る
- 基準：問題数の 8割以上＝◎、5割以上＝○、未満＝△、未入力＝空白

**連続してならぶ自動項目**（入力タブの並びと点数タブの並びが一定ズレで対応する範囲）は、
先頭の1マスに式を入れて **右へドラッグ→下へドラッグ** で一気に埋まる（相対参照が自動でずれる）。
例：入力_中一Cの「疑問詞〜Do/Does」は点数_Cの「疑問詞〜Do/Does」と＋1列ずつ対応 → 疑問詞のマスに入れて Do/Does までドラッグ。

**離れた場所にある自動項目**（例：代名詞・現在進行形）は、その列ごとに、対応する点数タブの列を指す式を入れて**下へだけドラッグ**。

### 手動列・足りない列

- **すでに手で◎○△を付けた列（連語・動詞・形容詞・スピーキング等）には式を入れない。** 上書きされないよう、ドラッグは**その手前の列で止める**
- テストにあるのに入力タブに列が無い項目（例：三単現）は、**列を足してから**式を入れる。通知表にも同じ項目の行を足す

### 通知表の確認

- 評価式は**列番号で直接取る形**（項目名で探すMATCH式は文字違いで壊れるので使わない）：
```
=IFERROR(VLOOKUP($B$2,入力_クラス名!$A:$列,列番号,FALSE),"")
```
- 新しく足した項目は、通知表にも行を足して式を入れる

## 大事な注意

- 実際のタブ名・列の並びは**スクショか本人のコピペで確認**。推測で書かない（全角半角の事故防止）
- セルは**1回クリックしてから⌘V**（ダブルクリック禁止）
- 貼り付け素材は「カンマ1行＋テキストを列に分割」か「縦ブロック」
- できあがったら docs/成績表システム.md のクラス表と数式を更新してコミット
- 返事は日本語・専門用語なし・絵文字でやさしく・1〜2ステップずつ

## 中一C の実例（このスキルで作った記録）

テスト：中1英語②後半（クリスティーナ先生）50点満点（ID `1eTspFvBkWSiYTlwkS35rOZZ7vmi2-Lrj470WahCgJkY`）。
- 点数_C 満点行（問題数）：`満点,5,10,3,6,6,8,7,8,3,4,6,3`（疑問詞=大問1-A6問＋対話4問=10）
- 点数_C 見出し：`名前,代名詞,疑問詞,時を表す語,副詞,副詞2,頻度の副詞,前置詞,be疑問否定,Can,Do/Does,三単現,現在進行形`
- 入力_中一C の並び（点数タブと順番がちがう！）：A名前, B疑問詞, C時を表す語, D副詞, E副詞2, F頻度の副詞, G前置詞, Hbe疑問否定, ICan, JDo/Does, K連語(手動), L動詞(手動), M形容詞(手動), N代名詞, O現在進行形, Pスピーキング(手動), Qコメント
- 疑問詞〜Do/Does（入力B〜J）は点数_Cの C〜K に＋1列ずつ対応 → 入力Bに入れて右へJまで＋下へドラッグ。式（Reina行）：
  `=IF(点数_C!C3="","",IFS(点数_C!C3>=点数_C!C$1*0.8,"◎",点数_C!C3>=点数_C!C$1*0.5,"○",TRUE,"△"))`
- 代名詞（入力N）→点数_C B列：`=IF(点数_C!B3="","",IFS(点数_C!B3>=点数_C!B$1*0.8,"◎",点数_C!B3>=点数_C!B$1*0.5,"○",TRUE,"△"))`
- 現在進行形（入力O）→点数_C M列：`=IF(点数_C!M3="","",IFS(点数_C!M3>=点数_C!M$1*0.8,"◎",点数_C!M3>=点数_C!M$1*0.5,"○",TRUE,"△"))`
- 手動：連語・動詞・形容詞・スピーキング（すでに手で採点済み。触らない）
- 三単現は入力タブに列が無かったので、列を足してから対応（点数_C L列）
- 教室独自：副詞=様子(slowly等)、副詞2=with/about等、前置詞=場所(in front of等)。docs参照。
