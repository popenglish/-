# /new-class — 新クラスの成績表セット作成

Pop English の成績表スプレッドシートに、新しいクラス用のタブ一式を作るための**コピペ素材と手順**を作る。

## 前提（このユーザーの環境）

- スプレッドシート：「イエロークラス成績表 2026年度前期」
  ID: `1USHJ1JGM-trt8bCdkh9qwT9ksJo1hAl6tAOYlP3vpeM`
- タブ名の付け方：`入力_クラス名`／`通知表_クラス名`／`点数_クラス名`
- **【重要ルール】タブ名に算用数字（1, 2, １, ２）を使わない。漢数字を使う**（例：中一A、中二）。全角・半角の見分けがつかず、過去に数式が動かない大事故になったため。
- 既存クラス例：イエロー、中一A、中一B、中一C、中二、中学準備、オレンジ
- ユーザーは日本語話者・スプレッドシート初心者。**1ステップずつ、やさしい日本語で**案内する。

## 手順

1. **ユーザーに確認する**（まだ分かっていなければ）
   - クラス名（→ タブ名を決める。算用数字はダメ）
   - 評価項目のリスト（なければ「テストのドキュメントを送ってもらえれば項目を提案します」と伝える。項目作りは test-items スキルの仕事）
   - 点数タブ（テストの正解数から◎○△を自動計算）も作るか
2. **タブ名を必ず確認する**：ユーザーに「作ったタブの名前をコピーして貼ってください」と頼み、**実際のタブ名をそのまま数式に使う**。自分で推測した表記を使わない。
3. 下の設計にそって、**コピペ素材を順番に出す**。一度に全部出さず、1ステップ完了を確認してから次へ。

## 各タブの設計

### ① 入力タブ（例：入力_中一A）

- 1行目＝見出し、2行目から生徒1人1行
- A列＝名前、B列〜＝評価項目、最後の列＝コメント
- 見出しは**カンマ区切りの1行**で渡し、こう案内する：
  1. A1セルを**1回クリック**して ⌘V で貼り付け
  2. A1を選んだまま「データ → テキストを列に分割 → 区切り文字：カンマ」

```
名前,項目1,項目2,…,スピーキング,コメント
```

- 手入力する列（スピーキングなど）には：「データ → データの入力規則 → プルダウン」で `◎,○,△,-` を設定
- **点数タブから自動計算する列にはプルダウンを付けない**（数式が入るため。付いていたら削除してもらう）

### ② 通知表タブ（例：通知表_中一A）

- A1＝タイトル（例：中一Aクラス　英語　通知表　2026年度 前期）
- A2＝「名前：」、**B2＝生徒名のプルダウン**（データの入力規則 → 範囲 `入力_中一A!A2:A100`）
- A5から下＝項目名（日本語と英語を**同じセル**に。例：`代名詞 / Pronouns`）
- B5から下＝説明文（**日本語のみ**。保護者向けのやさしい言葉。SVOO・SVOCなどの専門用語は禁止 →「『人に物をあげる』の文の形」のように言い換える）
- C5から下＝評価の数式。**列番号で直接取る形**を使う（項目名で探すMATCH式は文字が1字違うだけで空白になるので使わない）：

```
=IFERROR(VLOOKUP($B$2,'入力_中一A'!$A:$P,2,FALSE),"")
```

→ 最後の範囲（`$A:$P`）は入力タブの最終列に合わせる。数字（2, 3, 4…）が入力タブの列の位置。1行ずつ数字を変えた式を**縦一列のコピペブロック**で渡す。

- 評価の下に凡例：`学習状況・・・ ◎（十分達成しています）　○（おおむね達成しています）　△（努力をしましょう）　ー（欠席）`
- 先生からのコメント欄：コメント列の番号で `=IFERROR(VLOOKUP($B$2,'入力_中一A'!$A:$P,16,FALSE),"")`

### ③ 点数タブ（例：点数_A）— 希望があれば

- 1行目＝満点の行：`満点,4,10,4,…`（各項目のテストでの満点。カンマ区切りで渡して列に分割）
- 2行目＝見出し：`名前,項目1,項目2,…`
- A3＝`=入力_中一A!A2` を入れて下にドラッグ（名前が自動で並ぶ）
- B3から＝先生がテストの**正解数を手入力**する場所
- **変換の数式は点数タブには絶対に入れない**（循環参照エラー #REF! になる）。**入力タブのB2**に入れる：

```
=IF(点数_A!B3="","",IFS(点数_A!B3>=点数_A!B$1*0.8,"◎",点数_A!B3>=点数_A!B$1*0.5,"○",TRUE,"△"))
```

→ B2に貼ったら右へドラッグ（自動計算する列まで）、その後下へドラッグ。
→ 基準：満点の8割以上＝◎、5割以上＝○、それ未満＝△、未入力＝空白

## 貼り付けの案内で毎回伝えること

- セルは**1回クリック**してから ⌘V（ダブルクリックすると全部が1セルに入ってしまう）
- 数式が文字のまま表示されたら：「表示形式 → 数字 → 自動」にして、セルを消してもう一度貼る
- 縦のリストは一番上のセルに貼れば下に広がる。横並びはカンマ区切り＋「テキストを列に分割」

- 1メッセージ＝1〜2ステップまで。「できた」の返事を待ってから次へ
