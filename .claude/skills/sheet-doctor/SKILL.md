# /sheet-doctor — シートのお医者さん

成績表スプレッドシートで数式がうまく動かないときに、**過去に実際に起きた問題**を症状から順番にチェックして、直し方を1つずつ案内する。

## 進め方

1. まず症状を聞く（できれば**スクリーンショット**をもらう。エラーセルをクリックした状態だとエラーメッセージが見える）
2. 下の診断表から症状に合うものを選び、**可能性の高い順に1つずつ**確認してもらう
3. 一度に全部言わない。1チェック→結果を聞く→次へ

## 診断表（過去に実際に起きた問題）

### 症状：#REF! と出る

1. **「循環依存が検出されました」と出る場合**
   → 変換の数式（◎○△にする式）を**点数タブ自身に貼ってしまった**のが原因。
   → 直し方：点数タブの #REF! セルを削除。数式は**入力タブのB2**に貼る。
2. **タブ名が違う場合**（一番多い原因）
   → 数式の中のタブ名と、実際のタブ名が1文字でも違うと #REF! になる。
   → **見た目が同じでも全角・半角が違うことがある**（例：`中１`の「１」が全角、数式は半角の「1」）。過去にこれで長時間ハマった。
   → 直し方：タブを右クリック→「名前を変更」→タブ名を全選択してコピー→数式のタブ名部分に貼り直す。
   → **予防ルール：タブ名に算用数字を使わない。漢数字（中一A）にする。**
3. **IMPORTRANGE の #REF!**
   → 他人のシートを参照している（コピー元の持ち主のまま）。アクセス許可がないので動かない。
   → 直し方：IMPORTRANGE をやめて、値を直接書き込む方式にする。

### 症状：空白になる（エラーは出ない）

1. **IFERROR がエラーを隠している**。まずセルの式から `IFERROR(` と最後の `,"")` を一時的に外して、本当のエラー（#N/A か #REF! か）を確認する。
2. **#N/A の場合＝探している文字が見つからない**
   - MATCH式（項目名で探す式）を使っていると、通知表の項目名と入力タブの見出しが**1文字でも違う**と空白になる（例：`Adverbs` と `Adverbs2`、改行の有無）。
   - 直し方：**列番号で直接取る式に置き換える**のが確実：
     `=IFERROR(VLOOKUP($B$2,'入力_中一A'!$A:$P,6,FALSE),"")`（6＝入力タブでの列の位置）
   - または B2 の名前が入力タブのA列に**正確に同じ表記で**あるか確認。
3. **そもそも入力タブ側が空**：点数タブに正解数が入っているか、入力タブに変換の数式が入っているか確認。

### 症状：FALSE と表示される

→ 入力規則が「チェックボックス」になっている。
→ 直し方：セル範囲を選択 → データ → データの入力規則 → 既存ルールを**削除** → 新しく「プルダウン」で `◎,○,△,-` を設定。

### 症状：数式が文字のままセルに表示される

→ セルの表示形式が「書式なしテキスト」になっている。
→ 直し方：セルを選択 → 表示形式 → 数字 → **自動** → セルの中身を削除 → もう一度貼り付け。

### 症状：貼り付けたら全部が1つのセルに入った

→ セルを**ダブルクリック**（編集モード）で貼ったのが原因。
→ 直し方：セルを**1回だけクリック**して選択 → ⌘V。

### 症状：横並びに貼りたいのに縦になる／表が崩れる

→ カンマ区切りの1行で貼ってから「データ → テキストを列に分割 → カンマ」。
→ または縦に貼ってからコピー →「編集 → 特殊貼り付け → 転置して貼り付け（行と列を入れ替え）」。

### 症状：置換したら他のシートまで変わって壊れた

→ 検索と置換で範囲が「すべてのシート」になっていた。
→ 直し方：壊れたシートの数式を貼り直す。ファイル → 変更履歴 から戻すこともできる。
→ **予防ルール：検索と置換は必ず「このシートのみ」を選ぶ。** 開き方は「編集 → 検索と置換」（⌘+H はMacでは効かない。⌘+Shift+H）。

## 返事のしかた

- 日本語で、専門用語を避けてやさしく
- 「原因はこれかも」と決めつけず、確認→結果を聞く→次、の順で
- 直ったら、同じ事故を防ぐための一言（予防ルール）を添える
